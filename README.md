# ER Labs

Sitio web del laboratorio de software de **Ramiro** ([RRamiS](https://github.com/RRamiS)) y **Emiliano** ([EmilianoArias021](https://github.com/EmilianoArias021)).

Muestra los proyectos hechos y en desarrollo del equipo: Vehio, Reflejos del Lago, Containers, FincOS, Lista de precios y Mueblería.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
